# FEAT-000001 — Elenco Pratiche

## Obiettivo
Creare la prima versione funzionante della schermata Pratiche, seguendo il Blueprint V1.

## Funzionalità implementate
- nuova rotta /pratiche;
- voce Pratiche nella sidebar;
- pagina con titolo, ricerca, filtri per stato e priorità, pulsante di azzeramento e tabella responsive;
- colonne previste per codice, oggetto, stato, priorità, responsabile, gruppo, scadenza, ultimo aggiornamento e azioni;
- azioni di riga predisposte con notifiche informative;
- almeno 8 pratiche dimostrative in memoria;
- stato vuoto professionale in italiano;
- notifica per il pulsante Nuova pratica.

## Stato finale
- implementazione UI completa per l’elenco pratiche;
- dati dimostrativi in-memory;
- build e lint verificati tramite npm run build e npm run lint.
