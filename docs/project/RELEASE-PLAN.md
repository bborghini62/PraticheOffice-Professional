# Release plan

## Alpha
- Obiettivi: validare il framework base, la struttura architetturale e il primo set di funzionalità operative.
- Stato: completata con la release Alpha 0.1.

## Beta
- Obiettivi: consolidare i flussi operativi, migliorare la qualità dell’esperienza utente e preparare il prodotto a un uso più realistico.
- Deliverable: workflow più maturi, gestione delle notifiche e miglioramenti di usabilità.

## RC
- Obiettivi: stabilizzare il prodotto, correggere i bug critici e completare la documentazione di release.
- Deliverable: release candidate pronta per validazione esterna.

## 1.0
- Obiettivi: raggiungere una versione stabile, affidabile e pronta per l’uso in produzione.
- Deliverable: prodotto completo, documentato e supportato con i prerequisiti operativi necessari.
