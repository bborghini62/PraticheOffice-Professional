# Design System - PraticheOffice Professional

## Obiettivo
Definire una base grafica riutilizzabile per l’interfaccia dell’applicazione, mantenendo Material UI come standard principale.

## Principi
- coerenza visiva;
- componenti riutilizzabili;
- palette limitata e istituzionale;
- accessibilità e consistenza dei spacing e delle forme.

## Struttura
- theme: palette, tipografia, spacing, shadow e radius;
- components: bottoni, card, badge, filtri, empty state, dialog, overlay, tabella, sezioni e contenitori.
