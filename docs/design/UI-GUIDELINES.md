# UI Guidelines - PraticheOffice Professional

## Layout
- usare Paper e Box con spaziature coerenti;
- mantenere il layout a due colonne su desktop e una colonna su schermi piccoli;
- favorire contenitori leggibili con bordi arrotondati e ombre leggere.

## Tipografia
- titolo pagina: h4, peso 700;
- titolo sezione: h6, peso 600;
- titolo card: subtitle1, peso 600;
- testo normale: body1;
- testo piccolo: body2/caption.

## Componenti
- bottoni primari per azioni positive;
- bottoni secondari per azioni non primarie;
- bottoni di pericolo solo per azioni distruttive;
- badge per stato di pratiche;
- empty state per assenza di contenuti.
